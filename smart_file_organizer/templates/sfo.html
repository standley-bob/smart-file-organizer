Smart File Organizer

Sorts a messy inbox by type. Nothing leaves this sandbox, so anyone on this live page can try it.

How to tell it works

  1. Press Reset sample files so the inbox has the eight demo files.
  2. Check the plan: holiday.jpg should go to Images, demo.py to Code, and so on.
  3. Press Apply moves. The files should leave the inbox and show up in those folders below.

Or skip the clicks: Run live check sorts a private copy and prints pass/fail. Same result as /apps/organizer/check.json.
